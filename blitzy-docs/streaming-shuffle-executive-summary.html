The Problem

Status Quo · Sort-Based Shuffle

Shuffle Materialization Latency Bottleneck

  • Full map-side materialization blocks reducers until writers commit index files.
  • Disk round-trip adds seek latency even in memory.
  • Stage boundary stall forces consumers to idle during producer flush.
  • CPU overhead from sort and spill dominates small-record pipelines.

Components · AAP §0.1.1

Five New Components

Component Responsibility
StreamingShuffleManager Implements ShuffleManager SPI. Activated by spark.shuffle.manager=streaming. Holds SortShuffleManager as fallback delegate.
StreamingShuffleWriter Per-partition buffers capped at 20% executor memory. Pipelines bytes to consumers. CRC32C per 2 MB block.
BackpressureProtocol Heartbeat-based consumer signaling with 5 s timeout. Token-bucket rate limiting at 80% link capacity.
StreamingShuffleReader Polls producer for in-progress blocks. Validates checksums. Invalidates partial reads on connection timeout.
MemorySpillManager Polls memory at 100 ms. LRU eviction of largest partitions at 80% threshold. Delegates to BlockManager disk.
